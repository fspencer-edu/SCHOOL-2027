# What is AI

- Autonomous
	- Something that does not need to be provided constant instructions
- Adaptive
	- Can change its behaviour as the environment or problem space changes

## Defining AI

- AI is a synthetic system that exhibits "intelligent" behaviour

## Understanding that data is core to AI algorithms

- Data can represent values that are measured numerically, categorically
	- Quantitative and qualitative data
- Data is collected, recorded, and related by people based on specific context with a specific understanding of how the data may be used
- Information
	- Constructing meaningful insights to answer questions based on data
- Knowledge
	- Act of utilizing information with experiences and consciously applying it

## Viewing algorithms as instructions in recipes

- An algorithm is a set of instructions and rules provided as a specification to accomplish a specific goal
	- Accept inputs, and produce a output

## Problem types and problem solving paradigm

- Problems are classified based on the context and the goal

# Problem types and problem solving paradigms

### Search problems: Find a path to a solution

- A search problem involves a situation that has multiple possible solution
- Each represent a sequence of steps toward a goal
- Some solutions contain overlapping subset of paths
- Search a solution space
### Optimization problems: Find a good solution

- An optimization problem involves a situation in which there are a vast number of valid solutions and the absolute best solution is found
- Local best
	- Best solution within a specific area in the search space
- Global best
	- Best solution in the entire search space

### Prediction and classification problems: Learn from patterns in data

- Prediction problems are problems in which data is trying to find patterns
- Classification problems are similar to prediction problems
	- Categorize based on its features
### Clustering problems: Identify patterns in data

- Clustering problems include scenarios in which trends and relationships are uncovered from data
### Deterministic models: Same result each time it's calculated

- Deterministic models are models that, given a specific input, return a consistent output
### Stochastic/probabilistic models: Potentially different result each time it's calculated

- Probabilistic models are models that, given a specific input, return an outcome from a set of possible outcomes
- Controlled randomness

# Intuition fo AI concepts

### Narrow intelligence: Specific purpose solutions

- Narrow intelligence systems solve problems in a specific context or domain
- Can be combined in sensible ways to create a more general intelligence
### General intelligence: Humanlike solutions

- General intelligence is humanlike intelligence
- Learn from various experiences and interactions in the world
- Memory, spatial reasoning through visual inputs, use of knowledge, and extrapolation
### Super intelligence: The great unknown

- All machines are connected
### Old AI and new AI

- Old AI
	- Systems in which people encoded the rules that cause an algorithm to exhibit intelligent behaviour
	- In-depth knowledge or trial and error
- New AI
	- Create algorithms and models that learn from data and create their own rules that perform as accurately as, or better than, human created runes

### Search algorithms

- Search algorithms are useful for solving problems in which several actions are required to achieve a goal
- Evaluate future states and attempt to find the optimal path to the most valuable goal
### Biology-inspired algorithms

- Evolutionary algorithms are inspired by the theory of evolution
- Swarm intelligence
	- A group of "dumb" individuals exhibiting intelligent behaviour
- Ant-colony optimization and particle-swarm optimization

### Machine learning algorithm

- Supervised learning
	- Training models with algorithms when the training data has known outcomes
- Unsupervised learning
	- Uncovers hidden relationships and structure within the data that guides in asking relevant questions
- Reinforcement learning
	- Rewarding an individual if a useful action was performed and penalizing that individual if an unfavourable action was performed
### Deep learning algorithms

- Deep learning is a broader family of approaches and algorithms that are used to achieve narrow intelligence and strive toward general intelligence
- Solve a problem in a more general way
	- Spatial reasoning
	- Layers of artificial neural networks
