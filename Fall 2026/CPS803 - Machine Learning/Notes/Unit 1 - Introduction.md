- What is machine learning
	- Machine learning is about teaching a compute to become intelligent, by learning over time based on data and experience

- ML
	- Supervised
		- Classification
		- Regression
	- Unsupervised
		- Clustering
	- Reinforcement

- Supervised learning
	- Task of learning a mapping between a set of inputs to a set of outputs
	- Task of finding a function that generalizes the given data
- Unsupervised learning
	- Task of describing the patterns in the data and how to divide it
- Reinforcement learning
	- Learning based on rewarding for desired behaviours and punishing for undesired ones
