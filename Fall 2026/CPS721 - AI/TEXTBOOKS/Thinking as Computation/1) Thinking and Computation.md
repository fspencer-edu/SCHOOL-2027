### Logical entailment

- A collection of sentences logically entails another sentence if the truth of S is implicit in the truth of the $S_i$ sentences

$S_1, S_2, ..., S_n$

## Using what is known: The web of belief

- Network
	- Nodes for each of the terms and links between them according to the sentences in which they appear
- Web of belief
	- Sentences do not stand along but link to many others by virtue of the terms they use
	- Crawl over this web looking for connections among nodes

### Knowledge bases

- Knowledge base (KB)
	- Logical entailment of a collection of sentences
	- Set of premises about a subject
	- Find the logical entailment of all those sentences
- Knowledge base system
- Represent a system as symbolic sentences to form a KB
- Perform processing over the KB using the rules of logic to obtain new conclusions
- Have the system act based on the conclusions it can derive
