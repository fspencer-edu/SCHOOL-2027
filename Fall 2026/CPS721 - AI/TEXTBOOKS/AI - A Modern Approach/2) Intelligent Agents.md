# Agents and Environments

- Agent
	- Anything that can be viewed as perceiving its environment through sensors and acting upon that environment through actuators
- Percept
	- The content an agent's sensors are perceiving
- Percept sequence
	- Complete history what the agent has perceived
- Agent function
	- Maps any given percept sequence to an action
	- An abstract mathematical description
- Agent program
	- Concrete implementation
	- Running within some physical system
# Good Behaviour: the Concept of Rationality

- Rational agent
	- One that does the right thing

## Performance measures

- Consequentialism
	- Evaluate an agent's behaviour by its consequences
- Performance measures
	- Evaluates any given sequence of environment states
## Rationality

1) The performance measure that defined the criterion of success
2) The agent's prior knowledge of the environment
3) The actions that the agent can perform
4) Agent's percept sequence to data

- Definition of a rational agent
	- Selects an action that is expected to maximize its performance measure given the evidence provided by the percept sequence and build in knowledge

## Omniscience, learning, and autonomy

- Omniscience
	- Knows the actual outcome of its action and can act accordingly
