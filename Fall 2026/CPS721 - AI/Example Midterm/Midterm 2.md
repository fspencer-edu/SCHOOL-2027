```prolog
leaves(Tree, N)

% Base case: Empty tree has 0 leaves.
leaves(void, 0).

% Base case: A node with no children has 1 leaf.
leaves(tree(_, void, void), 1).

% Recursive case: Count leaves in both subtrees.
leaves(tree(Value, Left, Right), N) :-
	not((Left = void, Right = Void)),
	leaves(Left, NLeft),
	leaves(Right, NRight),
	N is NLeft + NRight.
	
% Example
leaves(
     tree(a,
          tree(b,
               tree(d, void, void),
               tree(e, void, void)),
          tree(c, void, void)),
     N).
```

A) Implement member/2 without append/3

```prolog
% Base case: X is the head of the list.
member(X, [X|Rest]).

% Recursive case: search the remaining list.
member(X, [Head|Rest]) :-
    member(X, Rest).
```

(B) Implement member/2 using append/3

```prolog
% Base case
append([], List, List).

% Recursive case
append([X|Xs], List, [X|Result]) :-
    append(Xs, List, Result).
    
member(X, List) :-
    append(Prefix, [X|Suffix], List).
```

(C) Evaluation trees with backtracking

`member(p, [d,f,p,r]).`

- Direct Recursion

```prolog
1. member(p, [d,f,p,r])
   - Check if p = d → False
   - Recursively search the remaining list.
2. member(p, [f,p,r])
   - Check if p = f → False
   - Recursively search the remaining list.
3. member(p, [p,r])
   - Check if p = p → True ✓
   - The query succeeds because p is in the list.
If Prolog is asked to find more solutions (;):
4. member(p, [r])
   - Check if p = r → False
   - Continue searching the remaining list.
5. member(p, [])
   - The list is empty.
   - No more elements to check.
   - Fails — no additional solutions.
```

- Using `append/3`

| Attempt | Prefix      | Remaining list | Check              | Result  |
| ------- | ----------- | -------------- | ------------------ | ------- |
| 1       | `[]`        | `[d,f,p,r]`    | `p = d`            | Fail    |
| 2       | `[d]`       | `[f,p,r]`      | `p = f`            | Fail    |
| 3       | `[d,f]`     | `[p,r]`        | `p = p`            | Success |
| 4       | `[d,f,p]`   | `[r]`          | `p = r`            | Fail    |
| 5       | `[d,f,p,r]` | `[]`           | No element remains | Fail    |

(2) Efficient Prolog program

```prolog
digit(0).
digit(1).
digit(2).
digit(3).
digit(4).
digit(5).
digit(6).
digit(7).
digit(8).
digit(9).

% Every element is different from X.
different_from(X, []).

different_from(X, [Y|Rest]) :-
    not(X = Y),
    different_from(X, Rest).

% Base case
all_different([]).

% Recursive case
all_different([X|Rest]) :-
    different_from(X, Rest),
    all_different(Rest).
    
% =========================================
    
solve(O, N, E, T, W) :-

    % Generate E.
    digit(E),

    % Units column: E + E = O + 10*C1
    Units is E + E,
    O is Units mod 10,
    C1 is Units // 10,

    % O cannot be zero or equal to E.
    O > 0,
    all_different([O,E]),

    % Generate N.
    digit(N),
    all_different([O,N,E]),

    % Tens column: N + N + C1 = W + 10*C2
    Tens is N + N + C1,
    W is Tens mod 10,
    C2 is Tens // 10,

    all_different([O,N,E,W]),

    % Hundreds column: O + O + C2 = T
    T is O + O + C2,

    % T must be a nonzero single digit.
    T >= 1,
    T =< 9,

    % All five digits must be different.
    all_different([O,N,E,T,W]).
```

The Turing test, proposed by Alan Turing in 1950, evaluates whether a machine can exhibit human-like intelligence through conversation. A human evaluator communicates with a machine and another human without knowing which is which. If the evaluator cannot reliably distinguish the machine from the human, the machine is considered to have passed the test. The test evaluates conversational behaviour rather than directly proving that the machine understands or thinks.
